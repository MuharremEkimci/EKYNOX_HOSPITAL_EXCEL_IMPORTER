# AI Destekli Eğitim Katılım Formu Dijitalleştirme Sistemi

Proje Özeti:
Bu proje, hastanelerde gerçekleştirilen eğitimlerde kullanılan fiziksel katılım formlarındaki el yazısı ad-soyad verilerini yapay zeka destekli görsel analiz ile okuyarak Excel raporlarına otomatik aktarmak amacıyla geliştirilmiş bir Windows masaüstü uygulamasıdır.

Uygulama; manuel veri giriş sürecini azaltmak, raporlama hızını artırmak ve kullanıcı doğrulama adımlarıyla veri kalitesini yükseltmek için tasarlanmıştır. Ayrıca, farklı AI sağlayıcılarıyla etkileşim kurulabilen uygulama içi chatbot modülü sayesinde model testi ve kullanıcı destekli deneme süreci de sunmaktadır.

Temel Özellikler:
- Kullanıcı adı/şifre ile giriş sistemi
- Kriptolu parola saklama
- Kurum tanımlama ve yönetimi
- Eğitmen seçimi ve eğitim kaydı oluşturma
- Çoklu görsel yükleme
- Görsel önizleme ve yakınlaştırma
- Yapay zeka sağlayıcı seçimi
- API key ve model yönetimi
- Model test ekranı
- Uygulama içi AI chatbot
- Çoklu model desteği
- Hata durumunda otomatik model geçişi
- Görsellerden isim-soyisim çıkarımı
- JSON veri işleme
- Excel verisi ile AI çıktısı karşılaştırma
- Eşleşen kayıtları görsel olarak doğrulama
- Manuel düzeltme desteği
- EPPlus ile Excel şablonlarına veri yazma
- Daha önce kayıtlı kişilerin tekrar eklenmesini engelleyen kontrol mantığı
